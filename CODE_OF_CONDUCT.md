# Code of conduct

We want participation in this project to be welcoming, respectful, and safe.

Be constructive, assume good intent, respect different experiences, and focus
criticism on ideas and code rather than people. Harassment, discrimination,
threats, doxxing, and publication of another person's private information are
not acceptable.

Project maintainers may edit or remove contributions and may temporarily or
permanently restrict participation when behavior harms the community. Report
conduct concerns privately to the maintainer through the contact options on
their GitHub profile. Reports will be handled as confidentially as practical.
